# B05 表格

Markdown 表格语法详解，以及 LZEditor 可视化表格编辑技巧。

---

## 基本语法

```markdown
| 列一 | 列二 | 列三 |
|:----:|-----:|:----|
| 居中 | 右对齐 | 左对齐 |
| 单元格 | 内容 | 示例 |
```

对齐方式由分隔行的冒号决定：

- \`:---:\` → 居中
- \`---:\` → 右对齐
- \`:---\` → 左对齐
- \`---\` → 默认（左对齐）

## 视觉编辑器

在 LZEditor 中选中表格后，会出现表格工具栏：

| 按钮 | 功能 |
|------|------|
| ➕ 上方插入行 — 在当前行上方插入新行 |
| ➕ 下方插入行 — 在当前行下方插入新行 |
| ⬅ 左侧插入列 — 在当前列左侧插入新列 |
| ➡ 右侧插入列 — 在当前列右侧插入新列 |
| 🗑 删除行 — 删除当前行 |
| 🗑 删除列 — 删除当前列 |
| ⊕ 合并单元格 — 选中多个单元格后合并 |
| ⊖ 拆分单元格 — 取消合并 |

---

## 表格快捷操作

| 操作 | 方法 |
|------|------|
| 进入表格 — \`Ctrl + Alt + T\` 或输入 \`/\` → 表格 |
| 下一个单元格 — \`Tab\` |
| 上一个单元格 — \`Shift + Tab\` |
| 新建表格 — 光标在行尾按 \`Tab\`，自动新增一行 |
| 删除整行 — 光标在行内，按 \`Ctrl + Shift + K\` |

## 复杂表格

### 合并单元格

目前 Markdown 原生语法不支持合并单元格，需使用 HTML 标签：

```html
<table>
  <tr>
    <th colspan="2">合并两列</th>
    <th>单独</th>
  </tr>
  <tr>
    <td>A</td>
    <td>B</td>
    <td>C</td>
  </tr>
</table>
```

---

### 表头固定

长表格在滚动时表头保持固定（阅读模式）：

```markdown
| 名称 | 数值 | 备注 |
|------|-----:|------|
| 项目A | 100 | 正常 |
| 项目B | 200 | 正常 |
<!-- 更多行... -->
```

## 表格导出

| 格式 | 说明 |
|------|------|
| **PDF** — 表格完整渲染，支持跨页 |
