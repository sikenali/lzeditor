# B02 图像

掌握图片插入、引用、尺寸控制和格式转换的各种技巧。

---

## 基本语法

```markdown
![替代文字](https://example.com/image.jpg)
```

替代文字在图片加载失败时显示，也便于屏幕阅读器识别。

---

## 本地图片

### 方式一：相对路径

```markdown
![截图](images/screenshot.png)
```

文件需放在 \`images/\` 同级目录或其子目录。

### 方式二：绝对路径

```markdown
![截图](D:/projects/docs/images/screenshot.png)
```

---

## 粘贴插入图片

LZEditor 支持以下方式插入本地图片：

- **复制粘贴** — 从系统剪贴板粘贴截图或图片，自动转为 base64 嵌入
- **拖拽** — 将图片文件拖入编辑区，自动插入
- **工具栏按钮** — 点击工具栏图片图标，选择本地文件

> 💡 粘贴的图片默认以内联 base64 形式保存，无需额外配置文件。

---

## 图片尺寸

```markdown
![图片](image.jpg =200x300)
```

| 写法 | 效果 |
|------|------|
| \`=200x300\` — 宽 200px，高 300px |
| \`=200\` — 宽 200px，高自动等比 |
| \`= \` — 仅设置宽度，高度等比 |
| \`=300x\` — 仅设置高度，宽度等比 |

---

## 图片居中对齐

```markdown
![图片](image.jpg =200x)
```

在段落前加空行，并使用 Markdown 的居中语法（部分渲染引擎支持）。

LZEditor 阅读模式会自动将独立图片居中显示。

---

## 图片标题（figcaption）

```markdown
![图片](image.jpg)
*图1：这是图片说明文字*
```

说明文字放在图片下方，斜体渲染。

---

## 图片链接

点击图片打开大图或跳转链接：

```markdown
[![图片](thumb.jpg)](full.jpg)
```

---

## 支持的图片格式

| 格式 | 说明 | 推荐场景 |
|------|------|---------|
| PNG — 无损压缩，支持透明 | 截图、图标 |
| JPG/JPEG — 有损压缩，文件小 | 照片 |
| GIF — 支持动画 | 简单动画 |
| SVG — 矢量图，无损缩放 | 图标、图表 |
| WebP — 现代格式，体积更小 | 网页配图 |
| BMP — 无损但文件大 | 不推荐 |

---

## 导出时的图片处理

| 格式 | 图片处理 |
|------|---------|
| **HTML** — 保留原图路径或 base64 |
| **PDF** — 内嵌图片，离线可读 |
| **DOCX** — 嵌入 Word 文档 |
| **PNG 截图** — 渲染后整体截图 |
| **EPUB** — 图片放入资源文件夹 |
