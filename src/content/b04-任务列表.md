# B04 任务列表

用任务列表管理待办事项，追踪进度一目了然。

---

## 基本语法

在列表项前加 \`[ ]\`（未勾选）或 \`[x]\`（已勾选）：

```markdown
- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个待办
```

---

## 渲染效果

- [ ] 未完成的任务
- [x] 已完成的任务
- [ ] 另一个待办

---

## 嵌套任务列表

任务列表支持多层嵌套：

```markdown
- [x] 第一阶段
  - [x] 子任务 1
  - [ ] 子任务 2
- [ ] 第二阶段
  - [ ] 子任务 A
  - [ ] 子任务 B
```

---

## 任务统计

在文档底部插入统计信息（手动）：

```markdown
## 进度

- 总任务：8
- 已完成：5
- 完成率：62.5%
```

---

## 任务列表 vs 普通列表

| 特性 | 任务列表 | 普通列表 |
|------|---------|---------|
| 复选框 — ✅ | ❌ |
| 状态标记 — [x]/[ ] | — |
| 导出打印 — 显示勾选状态 | 显示 · 符号 |
| 适用场景 — 待办/计划 | 普通列举 |

---

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| \`Ctrl + Shift + 9\` | 插入任务列表 |
| 光标在 \`[ ]\` 前 — 按 \`Space\` 切换勾选状态 |
| 光标在任务行 — 按 \`Tab\` 缩进为子任务 |
| 光标在子任务行 — 按 \`Shift + Tab\` 提升层级 |

---

## 任务列表导出

- **PDF**：勾选框会渲染为 ✓ / ○ 符号
- **HTML**：原生 \`<input type="checkbox" checked>\` 元素
- **DOCX**：转换为 Word 任务列表样式
