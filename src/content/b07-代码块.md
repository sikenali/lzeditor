# B07 代码块

深入掌握代码块的语法高亮、Mac 样式和复制功能。

---

## 基本语法

使用三个反引号 \````\` 包裹代码，并指定语言：

````markdown
\`\`\`javascript
function hello() {
  console.log('Hello LZEditor')
}
\`\`\`
````

---

## Mac 窗口样式

在「设置 → 编辑器 → 代码块」中开启「Mac 窗口样式」，代码块顶部会显示红黄绿三点装饰栏：

````markdown
```python
def hello():
    print("Hello LZEditor")
```
````

开启后渲染为：

```
🟡 🟢 🔴  filename.py
┌─────────────────────────┐
│ def hello():            │
│     print("Hello...")   │
└─────────────────────────┘
```

---

## 代码行号

开启「显示行号」后，代码块左侧会显示行号：

````markdown
```javascript [1,3,5]
const a = 1
const b = 2
const c = 3
```
````

方括号内指定要高亮的行号。

---

## 代码复制

每个代码块右上角有「复制」按钮（📋），点击一键复制代码内容。

复制内容包括：

- 代码原文（不含语言标识）
- 保留缩进和格式

---

## 行内代码

用单个反引号 \` \` 包裹行内代码：

```markdown
请使用 \`npm install\` 安装依赖。
```

行内代码不会被语法高亮，但会使用等宽字体显示。
