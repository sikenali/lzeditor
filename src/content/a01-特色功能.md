# A01 特色功能

LZEditor 的核心功能，覆盖写作全流程。

---

## 一、Markdown 编辑器

基于 TipTap 构建的富文本编辑器，支持完整的 Markdown 语法。

- **实时渲染** — 编辑区所见即所得，无需切换
- **分屏模式** — 左侧源码，右侧预览，同步滚动
- **代码高亮** — 支持 50+ 编程语言的语法着色
- **数学公式** — 内联 `$...$` 和独立 `$$...$$` 块，渲染为 KaTeX
- **表格编辑** — 支持增删行列、合并单元格

---

## 二、AI 辅助写作

选中任意文字，浮动工具栏自动出现，提供六大能力：

- ✍️ **改写** — 优化表达，适配商务/口语/正式风格
- 🎨 **润色** — 修正语法错误，提升流畅度
- ➡️ **续写** — 根据上下文延续内容，保持风格一致
- 📋 **摘要** — 提炼核心观点，生成结构化摘要
- 🌐 **翻译** — 多语言互译，保留原文格式
- 💬 **提问** — 针对内容提问，AI 智能回答

此外还支持：

- **斜杠命令** — 输入 \`/\` 快速插入标题、列表、代码块、表格等
- **全局对话框** — \`Ctrl/Cmd + /\` 直接打开 AI 输入框

---

## 三、多 Provider 支持

可灵活切换 AI 提供商，无需绑定单一服务：

- **Anthropic Claude** — Claude 3.5 Sonnet / Haiku
- **OpenAI** — GPT-4o / GPT-4 Turbo
- **Azure OpenAI** — 企业级部署
- **自定义基座** — 任意 OpenAI 兼容接口（如 LocalAI、vLLM）

在「设置 → AI」中配置，保存后即时生效。

---

## 四、多文档管理

左侧文档库支持完整的文档生命周期管理：

- **新建文档** — \`Ctrl + N\`，自动生成「未命名文档」
- **重命名** — 右键文档 → 重命名，标题即文档名
- **删除** — 右键文档 → 删除，支持撤销恢复
- **搜索** — 全文搜索当前文档库
- **最近打开** — 自动记录最近编辑过的文档
- **拖拽排序** — 可调整文档顺序

---

## 五、本地持久化

所有数据存储在浏览器 IndexedDB，零配置：

- **自动保存** — 每次输入后自动保存，无需手动操作
- **版本历史** — 每次保存生成快照，可随时回溯
- **离线可用** — 断开网络后仍可正常使用
- **隐私安全** — 数据不出本地，不被任何第三方收集

---

## 六、样式与主题

内置多种主题，支持高度自定义：

- 🌙 **暗夜霓虹** — 深色背景，紫色/青色点缀
- ☀️ **经典白** — 纯白背景，简洁舒适
- 📄 **纸张模式** — 暖黄底色，模拟纸质阅读
- 🌿 **森系绿** — 清新绿色调，护眼阅读

可自定义：

- 编辑器字体（衬线 / 无衬线 / 等宽）
- 字号大小（14px ~ 22px）
- 行间距（1.4 ~ 2.0）
- 内容宽度（全宽 / 适中 / 窄版）

---

## 七、多格式导出

一键导出为常用格式：

- 📄 **PDF** — 高质量打印输出，支持页眉页脚、页码
- 🌐 **HTML** — 单文件离线浏览，可直接发布
- 📑 **DOCX** — Microsoft Word 格式，便于协作编辑
- 📝 **Markdown** — 原始源码备份，通用性强
- 🖼 **PNG** — 当前视图截图，适合分享
- 📊 **SVG** — 矢量图格式，无损缩放
- 📈 **XLSX** — 表格导出为 Excel 格式

---

## 八、桌面应用

LZEditor 已打包为 Electron 桌面应用，支持：

- **Windows** — .exe 安装包 / Portable 免安装版
- **macOS** — .dmg 安装包
- **Linux** — .AppImage / .deb / .rpm

桌面版比 Web 版多了：

- 系统托盘集成
- 原生文件关联（双击 .md 文件打开）
- 更好的全屏体验
