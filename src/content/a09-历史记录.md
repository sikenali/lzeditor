# A09 历史记录

随时回溯文档版本，告别误删烦恼。

---

## 打开历史记录

### 方式一：工具栏按钮

点击工具栏「历史」图标（🕐），底部弹出历史面板。

### 方式二：右键菜单

在文档库中右键文档 → 「打开历史记录」。

### 方式三：历史面板

编辑区底部有历史面板入口，点击展开。

---

## 历史面板

历史面板显示当前文档的所有版本快照：

```
┌──────────────────────────────────────────┐
│  🕐 历史记录              [↺ 重做] [✕ 关闭] │
├──────────────────────────────────────────┤
│  今日 14:32  完成了大纲部分...   [↺ 回滚] │
│  今日 14:15  新建文档                 [↺ 回滚] │
│  今日 13:58  添加了功能介绍...       [↺ 回滚] │
│  今日 12:00  初始版本                 [↺ 回滚] │
└──────────────────────────────────────────┘
```

---

## 快照规则

| 规则 | 说明 |
|------|------|
| **自动保存** — 每次编辑后自动生成快照 |
| **最大数量** — 最多保留 50 个快照 |
| **快照间隔** — 同一内容 30 秒内不重复保存 |
| **自动清理** — 超过 50 个时删除最早快照 |

---

## 操作说明

### 回滚到历史版本

1. 在历史列表中点击目标版本
2. 预览窗口会显示该版本的文档内容
3. 确认无误后点击「回滚到此版本」
4. 文档内容将恢复为该版本状态

### 重做

回滚后，可以一键「重做」回到最新状态，避免误操作。

### 删除快照

右键点击任意快照 → 「删除此版本」，不会删除文档本身。

---

## 重要提示

> ⚠️ 回滚操作不可撤销，回滚前的修改将丢失。建议回滚前先备份重要内容。

> 💡 历史快照仅保存在本地浏览器，清除浏览器数据后历史记录会清空。

---

## 版本对比

点击任意两个版本，可查看差异：

- **文字差异** — 红色删除 / 绿色新增
- **数量统计** — 显示增加和删除的字数
- **时间跨度** — 显示两个版本之间的时间间隔

---

## 设置路径

「设置 → 编辑器 → 历史记录」中可配置：

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 最大快照数 | 50 | 最多保留的历史版本数量 |
| 自动保存间隔 | 30s | 两次保存之间的最小间隔 |
| 回滚确认 | 开启 | 回滚前弹出确认对话框 |
