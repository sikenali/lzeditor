# A05 快捷键

掌握快捷键，让写作效率倍增。

---

## 文本编辑

| 快捷键 | 功能 |
|--------|------|
| \`Ctrl + B\` | 粗体 |
| \`Ctrl + I\` | 斜体 |
| \`Ctrl + U\` | 下划线 |
| \`Ctrl + Shift + S\` | 删除线 |
| \`Ctrl + K\` | 插入链接 |
| \`Ctrl + Shift + K\` | 插入图片 |
| \`Ctrl + E\` | 插入公式 |

---

## 段落格式

| 快捷键 | 功能 |
|--------|------|
| \`Ctrl + Alt + 1\` | 一级标题 |
| \`Ctrl + Alt + 2\` | 二级标题 |
| \`Ctrl + Alt + 3\` | 三级标题 |
| \`Ctrl + Alt + 4\` | 四级标题 |
| \`Ctrl + ]\` | 增加缩进 |
| \`Ctrl + [\` | 减少缩进 |
| \`Ctrl + Shift + K\` | 转换为代码块 |

---

## 列表与表格

| 快捷键 | 功能 |
|--------|------|
| \`Ctrl + Shift + 7\` | 无序列表 |
| \`Ctrl + Shift + 8\` | 有序列表 |
| \`Ctrl + Shift + 9\` | 任务列表 |
| \`Ctrl + Alt + T\` | 插入表格 |
| \`Tab\` | 表格中前进单元格 |
| \`Shift + Tab\` | 表格中后退单元格 |

---

## 搜索与导航

| 快捷键 | 功能 |
|--------|------|
| \`Ctrl + F\` | 查找 |
| \`Ctrl + H\` | 查找替换 |
| \`Ctrl + G\` | 跳转到行 |
| \`Ctrl + Shift + F\` | 全局搜索文档 |
| \`Ctrl + P\` | 切换文档 |
| \`Ctrl + \`\` | 切换代码模式 |

---

## AI 功能

| 快捷键 | 功能 |
|--------|------|
| \`Ctrl + /\` | 打开 AI 对话框 |
| \`Enter\` | 发送 AI 消息 |
| \`Esc\` | 关闭 AI 对话框 |
| \`Ctrl + Shift + P\` | AI 浮动工具栏（选中文字后） |

---

## 界面操作

| 快捷键 | 功能 |
|--------|------|
| \`F11\` | 全屏模式 |
| \`Ctrl + Shift + L\` | 切换大纲视图 |
| \`Ctrl + Shift + O\` | 切换阅读模式 |
| \`Ctrl + Shift + E\` | 切换预览面板 |
| \`Ctrl + ,\` | 打开设置 |

---

## macOS 对应

macOS 用户将 \`Ctrl\` 替换为 \`Cmd (⌘)\`：

| macOS 快捷键 | 功能 |
|--------------|------|
| \`Cmd + B\` | 粗体 |
| \`Cmd + I\` | 斜体 |
| \`Cmd + K\` | 插入链接 |
| \`Cmd + /\` | AI 对话框 |
| \`Cmd + F\` | 查找 |
| \`Cmd + H\` | 查找替换 |

---

## 自定义快捷键

LZEditor 暂时不支持自定义快捷键，但可通过「设置 → 编辑器」调整部分行为。

> 📌 **提示**：按 \`Ctrl + /\` 打开 AI 对话框，输入「列出快捷键」可让 AI 为你生成快捷键速查表。
