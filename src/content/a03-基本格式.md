# A03 基本格式

Markdown 基础语法速查，LZEditor 完整支持。

---

## 标题

使用 \`#\` 符号，1~6 级标题：

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

在编辑区输入 \`# 标题\` 后按空格，TipTap 会自动转换为标题块。

---

## 文本样式

| 语法 | 效果 | 快捷键 |
|------|------|--------|
| \`**文字**\` | **粗体** | Ctrl+B |
| \`*文字*\` | *斜体* | Ctrl+I |
| \`~~文字~~\` | ~~删除线~~ | Ctrl+Shift+X |
| \`**\*文字\***\` | ***粗斜体*** | — |
| \` \`文字\` \` | \`行内代码\` | — |
| \`==文字==\` | ==高亮== | — |

---

## 段落与换行

- 空一行 = 新段落
- 两个空格 + 回车 = 软换行（不分段）
- 三个空格 + 回车 = 硬分割

```markdown
这是第一段。

这是第二段。（中间空一行）

第一行  
第二行（行尾两个空格）
```

## 列表

### 无序列表

```markdown
- 项目一
- 项目二
  - 子项目 A
  - 子项目 B
- 项目三
```

### 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
   1. 子步骤一
   2. 子步骤二
```

### 任务列表

```markdown
- [x] 已完成任务
- [ ] 未完成任务
- [ ] 待办事项
```

---

## 引用

```markdown
> 这是一段引用文字
> 可以有多行
>
> > 这是嵌套引用
```

## 代码块

使用三个反引号 \````\` 包裹，可指定语言：

````markdown
\`\`\`javascript
const greeting = 'Hello LZEditor'
console.log(greeting)
\`\`\`

\`\`\`python
def hello():
    print("Hello LZEditor")
\`\`\`

\`\`\`bash
npm run dev
\`\`\`
````

LZEditor 支持 50+ 编程语言的语法高亮。

## 链接

```markdown
[链接文字](https://example.com)
[带标题的链接](https://example.com "提示文字")
<https://auto.link.com>           <!-- 自动链接 -->
```

---

## 图片

```markdown
![替代文字](https://example.com/image.jpg)
![本地图片](images/photo.png)
```

> 💡 LZEditor 支持粘贴图片自动上传，也可拖拽图片到编辑区插入。

---

## 表格

```markdown
| 列一 | 列二 | 列三 |
|:----:|-----:|:----|
| 居中 | 右对齐 | 左对齐 |
| 单元格 | 内容 | 示例 |
```

在编辑区使用 \`/\` 命令 → 插入表格，可可视化增删行列。

---

## 分割线

```markdown
---
***
___
```

三种写法效果相同，生成水平分割线。

---

## 特殊字符转义

在字符前加反斜杠 \`\\` 可禁用 Markdown 语法：

```markdown
\*这不是斜体\*
\# 这不是标题
\[不是链接\]
```

## 常用符号

| 符号 | 名称 |
|------|------|
| \`&nbsp;\` | 不间断空格 |
| \`&mdash;\` | 长破折号 — |
| \`&ndash;\` | 短破折号 – |
| \`&laquo;\` | 左尖括号 « |
| \`&raquo;\` | 右尖括号 » |
| \`&hellip;\` | 省略号 … |
| \`&copy;\` | 版权 © |
| \`&reg;\` | 注册 ® |
