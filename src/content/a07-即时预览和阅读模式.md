# A07 即时预览和阅读模式

掌握 LZEditor 三种核心视图模式，找到最适合你的写作方式。

---

## 一、编辑模式（默认）

Markdown 源码与富文本实时同步，所见即所得。

- 左侧输入 Markdown 语法
- 右侧实时渲染预览
- 支持分屏比例调节（拖动中间分割线）
- 快捷键 \`Ctrl + \`\` 切换

---

## 二、即时预览模式

无需分屏，所有内容直接在编辑区渲染：

1. 点击右上角「预览」按钮（👁️ 图标）
2. 或在编辑区输入 Markdown 后立即看到渲染效果
3. 再次点击退出预览，回到编辑状态

即时预览模式下：

- 光标不可编辑（预览只读）
- 点击任意位置返回编辑模式
- 支持滚动同步

---

## 三、阅读模式

沉浸式单栏阅读体验，适合长文阅读和最终呈现：

### 开启方式

- 点击工具栏「阅读」按钮（📖 图标）
- 或快捷键 \`Ctrl + Shift + O\`
- 或从文件菜单选择「进入阅读模式」

### 阅读模式特性

- **单栏布局** — 居中展示，最大宽度 760px
- **无工具栏干扰** — 顶部隐藏，鼠标悬停时出现
- **大纲导航** — 左侧浮动大纲面板
- **进度指示** — 顶部显示阅读进度条
- **字体可调** — 设置中可调节阅读字体、字号、行距
- **主题适配** — 自动跟随当前主题色

### 阅读模式布局

| 布局 | 说明 |
|------|------|
| **标准** | 居中单栏，760px 宽 |
| **窄栏** | 530px 宽，适合手机阅读 |
| **宽屏** | 1000px 宽，适合大屏 |

### 阅读模式快捷键

| 快捷键 | 功能 |
|--------|------|
| \`Page Up\` | 上一页 |
| \`Page Down\` | 下一页 |
| \`Home\` | 跳到开头 |
| \`End\` | 跳到结尾 |
| \`Esc\` | 退出阅读模式 |

---

## 模式切换流程

```
编辑模式 ──(F11)──> 全屏编辑
    │
    ├──(点击预览)──> 即时预览
    │
    └──(点击阅读)──> 阅读模式
                        │
                        ├──(大纲)──> 显示大纲面板
                        ├──(主题)──> 切换主题
                        └──(Esc)──> 返回编辑模式
```

---

## 推荐场景

| 场景 | 推荐模式 |
|------|---------|
| 新文档创作 | 编辑模式 |
| 检查格式效果 | 即时预览 |
| 长文最终审阅 | 阅读模式 |
| 向他人展示 | 阅读模式 |
| 代码编写 | 编辑模式（分屏） |
