# B10 高级格式

掌握 LZEditor 中的高级排版技巧，让文档更加专业。

---

## 下标与上标

使用 \`<sub>\` 和 \`<sup>\` 标签：

```html
H<sub>2</sub>O  水的化学式
E=mc<sup>2</sup>  质能方程
x<sup>2</sup> + y<sup>2</sup> = r<sup>2</sup>
```

渲染效果：H<sub>2</sub>O　　E=mc<sup>2</sup>

---

## 删除线与下划线

```markdown
~~删除线文字~~
<u>下划线文字</u>
```

---

## 自定义样式

通过 HTML 标签实现精细控制：

### 文字颜色

```html
<span style="color:#e74c3c">红色</span>
<span style="color:#27ae60">绿色</span>
<span style="color:#3498db">蓝色</span>
```

### 文字大小

```html
<span style="font-size:24px">大字体</span>
<span style="font-size:12px">小字体</span>
```

### 文字背景

```html
<span style="background:#fff3cd;padding:2px 4px;border-radius:3px">高亮背景</span>
```

## 特殊字符

| 字符 | HTML 实体 | Unicode |
|------|-----------|---------|
| © 版权 — \`&copy;\` | \`&#169;\` |
| ® 注册 — \`&reg;\` | \`&#174;\` |
| § 分节 — \`&sect;\` | \`&#167;\` |
| ¶ 段落 — \`&para;\` | \`&#182;\` |
| † dagger — \`&dagger;\` | \`&#8224;\` |
| ‡ double dagger — \`&Dagger;\` | \`&#8225;\` |
| ™ 商标 — \`&trade;\` | \`&#8482;\` |
| ℃ 摄氏度 — \`&deg;\`C | \`&#176;\` |
| ± 正负 — \`&plusmn;\` | \`&#177;\` |
| × 乘号 — \`&times;\` | \`&#215;\` |
| ÷ 除号 — \`&divide;\` | \`&#247;\` |

---

## 非断行空格

使用 \`&nbsp;\` 防止单词在行末被断开：

```html
10&nbsp;km &nbsp;&nbsp;&nbsp; （多个空格）
```

---

## 自定义 CSS

在「设置 → 样式 → 自定义 CSS」中注入个人样式：

```css
/* 修改引用块样式 */
blockquote {
  border-left-color: #6366f1 !important;
  background: #f8f7ff !important;
}

/* 修改代码块背景 */
pre {
  border-radius: 8px !important;
}
```

---

## 自定义前缀

可以为特定段落添加自定义类名，实现差异化样式：

```markdown
:::warning
这是警告样式段落
:::

:::info
这是信息样式段落
:::
```

---

## 分页符（导出 PDF 用）

在文档中插入分页符，控制 PDF 导出时的分页位置：

```html
<div style="page-break-after: always;"></div>
```

---

## 大纲级别控制

通过标题层级控制文档结构深度，LZEditor 大纲视图最多显示 6 级：

```markdown
# 一级
## 二级
### 三级
#### 四级
##### 五级
###### 六级
```

建议实际写作控制在 3 级以内，避免结构过于复杂。
