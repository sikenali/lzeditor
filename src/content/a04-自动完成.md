# A04 自动完成

LZEditor 提供多种智能补全，提升写作效率。

---

## 斜杠命令

在编辑区输入 \`/\` 即可唤起命令面板，支持以下操作：

### 文本插入

| 命令 | 说明 |
|------|------|
| \`/标题 1\` | 插入一级标题 |
| \`/标题 2\` | 插入二级标题 |
| \`/标题 3\` | 插入三级标题 |
| \`/段落\` | 插入普通段落 |
| \`/引用\` | 插入引用块 |
| \`/分割线\` | 插入水平分割线 |

### 列表与结构

| 命令 | 说明 |
|------|------|
| \`/无序列表\` | 插入无序列表 |
| \`/有序列表\` | 插入有序列表 |
| \`/任务列表\` | 插入任务列表 |
| \`/复选框\` | 插入单个复选框 |

### 代码与表格

| 命令 | 说明 |
|------|------|
| \`/代码\` | 插入代码块 |
| \`/表格\` | 插入表格（可自定义行列数） |
| \`/公式\` | 插入数学公式 |

### AI 相关

| 命令 | 说明 |
|------|------|
| \`/改写\` | 对选中文本进行 AI 改写 |
| \`/润色\` | 对选中文本进行 AI 润色 |
| \`/续写\` | AI 继续当前内容 |
| \`/摘要\` | 对选中文本生成摘要 |
| \`/翻译\` | 对选中文本进行翻译 |
| \`/提问\` | 针对选中文本向 AI 提问 |
| \`/扩写\` | 扩展当前内容 |
| \`/简化\` | 简化当前内容 |

## 自动补全

### 标点补全

输入左括号时自动补全右括号：

| 输入 | 结果 |
|------|------|
| \`(\` | \`()\` 光标在中间 |
| \`[\` | \`[]\` 光标在中间 |
| \`{\` | \`{}\` 光标在中间 |
| \`\"\` | \`""\` 光标在中间 |
| \`\'\` | \`''\` 光标在中间 |
| \`《\` | \`《》\` 光标在中间 |
| \`「\` | \`「」\` 光标在中间 |

### 列表自动续接

输入 \`-\` 后跟空格，或 \`1.\` 后跟空格，下一行会自动延续列表格式。

### 表格自动续接

在表格最后一列输入 \`Tab\`，自动新增一列；在表格最后一行下方输入 \`Tab\`，自动新增一行。

---

## 关键词补全

在设置中可开启「关键词自动补全」：

- 输入 \`js\` + Tab → 生成 JavaScript 代码块
- 输入 \`py\` + Tab → 生成 Python 代码块
- 输入 \`bash\` + Tab → 生成 Bash 代码块

---

## 智能段落

LZEditor 会根据上下文自动推断段落格式：

- 行首输入 \`>\` 自动转为引用
- 行首输入 \`-\` 自动转为列表
- 行首输入 \`1.\` 自动转为有序列表
- 连续输入 \`---\` 自动转为分割线

---

## 设置路径

「设置 → 编辑器 → 自动完成」中可配置：

- 启用自动补全括号
- 启用列表自动续接
- 启用关键词补全
- 启用 AI 智能续写
