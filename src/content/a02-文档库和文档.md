# A02 文档库和文档

掌握多文档管理，让写作井井有条。

---

## 打开文档库

点击工具栏左侧的「文档库」图标（📂），侧边栏会滑出文档列表。

```
┌──────────────────────────────────┐
│ 📂 文档库          [+ 新建] [🔍] │
├──────────────────────────────────┤
│ Default                          │
│  📄 欢迎文档                      │
│  📄 项目笔记                      │
│  📄 周报-2024-W38                 │
│  📄 技术博客·React最佳实践        │
│                                  │
│  工作簿                          │
│  📄 会议记录-10月15日             │
│  📄 产品需求文档                  │
└──────────────────────────────────┘
```

---

## 新建文档

有三种方式创建新文档：

1. **点击工具栏「新建」按钮** — 顶部工具栏左侧 \`+\` 图标
2. **快捷键** — \`Ctrl + N\`（Windows/Linux）/ \`Cmd + N\`（Mac）
3. **文档库面板底部「新建」** — 在文档库面板底部点击新建按钮

新建文档默认标题为「未命名文档 N」（N 为序号），可立即重命名。

---

## 重命名文档

右键点击文档 → 选择「重命名」，或直接点击文档标题进行编辑。

快捷键：选中文档后按 \`F2\` 进入重命名模式，\`Enter\` 确认，\`Esc\` 取消。

---

## 删除文档

右键点击文档 → 选择「删除」。

> ⚠️ 删除后文档会进入「回收站」，7 天内可恢复。超过 7 天自动永久删除。

---

## 搜索文档

文档库顶部有搜索框，支持：

- **标题搜索** — 匹配文档名称
- **全文搜索** — 匹配文档内容
- **快捷键** — \`Ctrl + Shift + F\` 打开全局搜索

---

## 最近打开

文档库底部显示「最近打开」列表，最多保留 10 条记录。点击即可快速切换。

---

## 文档库分组

文档可按文件夹分组管理。右键文档库空白处 → 「新建分组」，然后将文档拖入对应分组。

分组支持：
- **重命名** — 右键分组 → 重命名
- **删除** — 右键分组 → 删除（文档不会丢失）
- **拖拽排序** — 拖动分组调整顺序

---

## 文档元数据

每个文档包含以下元数据：

| 字段 | 说明 |
|------|------|
| **标题** | 文档名，显示在文档库列表 |
| **路径** | 所在分组路径 |
| **创建时间** | 首次创建的时间戳 |
| **更新时间** | 最后一次保存的时间戳 |
| **字数** | 当前文档的字符数 |
| **行数** | 当前文档的换行数 |

---

## 快捷操作

| 操作 | 方法 |
|------|------|
| 切换文档 | 点击文档名 |
| 重命名 | 右键 → 重命名 / 选中后按 \`F2\` |
| 删除 | 右键 → 删除 |
| 复制内容 | 右键 → 复制文档内容到剪贴板 |
| 导出 | 右键 → 导出为 PDF/HTML/DOCX |
| 查看历史 | 右键 → 打开历史记录 |
