# B01 链接

深入理解 LZEditor 中的链接功能，掌握超链接、锚点、邮件链接的编写技巧。

---

## 基本链接

```markdown
[链接文字](https://example.com)
```

渲染结果：[链接文字](https://example.com)

---

## 带标题的链接

```markdown
[链接文字](https://example.com "鼠标悬停提示")
```

---

## 自动链接

在文字前后加 \`<\` 和 \`>\`，Markdown 会自动识别为链接：

```markdown
<https://example.com>
<mailto:hello@example.com>
```

---

## 锚点链接（跳转到文档内位置）

### 方式一：标题锚点

每个 \`#\` 标题会自动生成锚点，格式为 \`#标题文字\` 转小写、空格变 \`-\`：

```markdown
## 快速开始

...

[回到顶部](#快速开始)
```

> ⚠️ LZEditor 阅读模式和导出 PDF 时锚点有效，编辑模式下点击锚点不跳转。

### 方式二：自定义锚点

```markdown
<span id="my-anchor"></span>

[跳到指定位置](#my-anchor)
```

---

## 图片链接

点击图片可放大查看：

```markdown
[![图片文字](https://example.com/thumb.jpg)](https://example.com/full.jpg)
```

---

## 引用式链接

适合链接地址很长或需要复用的情况：

```markdown
[本文参考][ref1]

[ref1]: https://example.com/very-long-url "参考来源"
```

---

## 相对链接

链接到本地其他文档（需在同一文档库内）：

```markdown
[打开帮助文档](a01-特色功能)
```

---

## 邮件链接

```markdown
[email me](mailto:hello@example.com?subject=问候&body=你好)
```

---

## 注意事项

- **链接中有空格** — 用 `%20` 替代，或用 `< >` 包裹
- **链接含特殊字符** — 对 `()` `[]` 等用 `\` 转义
- **同一页面多次引用** — 使用引用式链接避免地址重复
