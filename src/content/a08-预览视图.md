# A08 预览视图

右侧预览面板，实时查看 Markdown 渲染效果。

---

## 打开预览面板

### 方式一：工具栏按钮

点击工具栏右侧「预览」图标（👁️），右侧滑出预览面板。

### 方式二：快捷键

\`Ctrl + Shift + E\` 切换预览面板的显示/隐藏。

### 方式三：侧边栏

在左侧文档库右侧的侧边栏区域，点击「预览」标签页。

---

## 预览面板功能

预览面板提供两种视图模式：

| 模式 | 说明 | 切换方式 |
|------|------|---------|
| 富文本预览 — 渲染后的 HTML 效果 | 默认 |
| 源码视图 — 原始 Markdown 源码 | 点击「源码」按钮 |

---

## 富文本预览

渲染后的文档效果，包含：

- 标题层级样式
- 段落间距
- 代码块高亮
- 表格样式
- 引用样式
- 数学公式（KaTeX）

支持缩放：

- \`Ctrl + /\` — 放大
- \`Ctrl + -\` — 缩小
- \`Ctrl + 0\` — 重置

---

## 源码视图

显示当前文档的原始 Markdown 源码，便于：

- 检查语法是否正确
- 复制特定段落
- 学习 Markdown 语法

在源码视图中可：

- 一键复制全部源码（📋 按钮）
- 搜索替换（Ctrl+F）

---

## 预览同步

预览面板支持多种同步方式：

- **滚动同步** — 编辑区滚动时预览区同步滚动
- **光标同步** — 光标所在行在预览中高亮
- **实时更新** — 输入后立即渲染，无需手动刷新
- **导出同步** — 导出时预览与实际输出一致

---

## 公众号预览

预览面板右上角有「公众号」按钮，点击后可：

- 将渲染后的 HTML 复制为富文本
- 可直接粘贴到微信公众号编辑器
- 保留图片、表格、代码块等格式

---

## 预览面板设置

「设置 → 编辑器 → 预览」中可配置：

- **默认打开预览** — 启动时自动显示预览面板
- **同步滚动** — 编辑与预览联动滚动
- **代码主题** — 预览中代码块的高亮主题
- **字体大小** — 预览内容的基准字号
