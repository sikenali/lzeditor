# A10 拼写检查

LZEditor 内置拼写检查功能，帮助发现文字错误。

---

## 开启拼写检查

### 方式一：设置面板

「设置 → 编辑器 → 拼写检查」中开启，并选择检查语言。

### 方式二：快捷键

\`Ctrl + Shift + P\` 快速切换拼写检查开关。

---

## 检查语言支持

| 语言 | 代码 | 说明 |
|------|------|------|
| 中文 | \`zh-CN\` | 简体中文检查 |
| 英文（美式） | \`en-US\` | 默认语言 |
| 英文（英式） | \`en-GB\` | 英式拼写 |
| 日文 | \`ja-JP\` | 日语假名检查 |
| 法文 | \`fr-FR\` | 法语检查 |
| 德文 | \`de-DE\` | 德语检查 |

---

## 错误提示

拼写检查发现错误时，会在文字下方显示波浪线：

| 标记 | 含义 |
|------|------|
| 🔴 **红色波浪线** | 拼写错误，词不在词典中 |
| 🟡 **黄色波浪线** | 语法建议，格式不规范 |
| 🟢 **绿色波浪线** | 风格建议，可读性优化 |

---

## 操作建议

将鼠标悬停在带波浪线的文字上，会弹出建议菜单：

```
━━━━━━━━━━━━━━━━━━━━━
🔴 拼写错误：recieve
   → receive  ← 建议修改
   → recipe   ← 替代词
   → 忽略此词
   → 全部忽略
━━━━━━━━━━━━━━━━━━━━━
```

---

## 词典管理

### 添加自定义词

在「设置 → 拼写检查 → 自定义词典」中：

1. 输入需要加入词典的词汇
2. 点击「添加」
3. 该词将不再被标记为错误

### 批量导入

支持从文本文件批量导入自定义词汇，每行一个词。

---

## 排除检查

以下情况会跳过拼写检查：

| 情况 | 说明 |
|------|------|
| 代码块 | \```` ``` ```\` 内的内容不检查 |
| 行内代码 | \` \` 内的内容不检查 |
| URL | 网址链接不检查 |
| 邮件地址 | 邮箱地址不检查 |
| 已标注词汇 | 自定义词典中的词不检查 |

---

## 性能说明

- 拼写检查在后台线程运行，不影响编辑流畅度
- 大型文档（>10000字）首次检查可能需要数秒
- 检查完成后会缓存结果，后续编辑增量更新

---

## 设置路径

「设置 → 编辑器 → 拼写检查」：

- [ ] 启用拼写检查
- 语言选择下拉框
- 自定义词典管理
- 排除范围勾选
