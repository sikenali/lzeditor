# B03 脚注

为文档添加学术级注释，正文与注释分离，阅读体验更清爽。

---

## 基本语法

在正文中使用 \`[^标签]\` 引用脚注，在文档末尾定义脚注内容：

```markdown
LZEditor 是一款优秀的 Markdown 编辑器[^1]。

[^1]: 这是脚注的内容，会显示在页面底部。
```

---

## 多脚注

同一文档可添加多个脚注，互不干扰：

```markdown
TipTap 提供了强大的扩展机制[^tip]，支持自定义插件[^plugin]。

[^tip]: TipTap 是基于 ProseMirror 的富文本编辑器框架。
[^plugin]: 插件可注册为 Command、Extension 等类型。
```

---

## 脚注重复引用

同一脚注可被多次引用，渲染时自动生成相同编号：

```markdown
LZEditor 基于 TipTap 开发[^tip]，TipTap 由 Markus Oberlehner 创建[^tip]。
```

---

## 脚注中可以使用其他 Markdown

脚注内容支持标题、链接、代码等：

```markdown
更多信息请参考 [官方文档](https://example.com)[^ref]。

[^ref]: 官方文档地址：https://example.com/docs
```

---

## 行内脚注

脚注定义可以紧跟在引用之后（写在同一行）：

```markdown
LZEditor 很好用[^这是行内脚注]。
```

---

## 样式定制

在「设置 → 样式」中可调整脚注的字体大小和颜色：

- **脚注字号** — 12px
- **脚注颜色** — `#888`
- **分隔线** — 开启，正文与脚注之间的分割线

---

## 导出脚注

- **HTML** — 渲染为 `<sup>` + `<section class="footnotes">`
- **PDF** — 脚注显示在页面底部
- **DOCX** — 转换为 Word 脚注
- **Markdown** — 保留原始脚注语法
