# 历史页记录硬截断最近 10 条 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 历史页（HistoryPanel）时间线硬性截断为最近 10 条记录（无展开入口）。

**Architecture:** 在 `mergeTimeline`（唯一调用方是 HistoryPanel）排序后 `.slice(0, MAX_TIMELINE)`，`MAX_TIMELINE = 10`。HistoryPanel 无需改动（它渲染 `merged`，mergeTimeline 返回 ≤10 后自动只显示 10 根柱）。

**Tech Stack:** React + Vite；node:test 纯函数单测（沿用 `tests/history-timeline.test.mjs`）。

**Spec:** `docs/superpowers/specs/2026-11-17-history-cap-10-design.md`

## Global Constraints

- `MAX_TIMELINE = 10`（历史页展示上限，命名风格与 `MAX_VERSIONS` 一致）。
- 合并时间线按 `ts` 倒序（新→旧），最近 10 条 = 排序后前 10 条 = `.slice(0, 10)`。
- 不改 `MAX_VERSIONS`（本地版本上限）与 `MAX_GIT_COMMITS`（git 拉取深度）；不改选中/预览/回滚/重播逻辑。

## Review Focus

- **本地无 git 时记录数不变** —— Web/LPK（无 Electron git）下本地版本已 ≤10，截断应为 no-op。测试：合并输入 ≤10 条时原样返回。
- **有 git 提交时只显示最近 10 条** —— 本地 10 + git 50 混排后仍只取最新 10。测试：>10 条输入 → 只返回最新 10 条。

- [ ] **Step 1: 写失败测试（history-timeline.test.mjs 末尾追加）**

```js
// ── 历史页硬截断：mergeTimeline 只返回最近 MAX_TIMELINE 条 ──
test('mergeTimeline：超过 10 条 → 只返回最近 10 条（历史页硬截断）', () => {
  const local = Array.from({ length: 8 }, (_, i) => ({ id: `L${i}`, ts: i * 100, source: 'local', time: '', date: '', desc: '', changes: 1, html: '', md: '' }))
  const git = Array.from({ length: 8 }, (_, i) => ({ oid: `G${i}`, message: 'm', author: 'a', ts: 1000 + i * 100, changes: 1, gitPath: 'f.md' }))
  const merged = mergeTimeline(local, git, 'f.md')
  assert.equal(merged.length, MAX_TIMELINE, '必须只返回 10 条')
  // 必须是最近 10 条：ts 最大的 10 个
  const all = [...local, ...git].sort((a, b) => b.ts - a.ts)
  assert.deepEqual(merged.map(v => v.id), all.slice(0, 10).map(v => v.id), '返回的必须是最新的 10 条')
})

test('mergeTimeline：≤10 条 → 原样返回（本地无 git 时 no-op）', () => {
  const local = Array.from({ length: 5 }, (_, i) => ({ id: `L${i}`, ts: i * 100, source: 'local', time: '', date: '', desc: '', changes: 1, html: '', md: '' }))
  const merged = mergeTimeline(local, [], undefined)
  assert.equal(merged.length, 5, '≤10 条必须原样返回')
})
```
