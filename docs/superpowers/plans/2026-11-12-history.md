# 历史功能：Git 提交 + 本地编辑合并时间线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让历史面板显示当前文档的合并时间线——git 仓库文件的提交历史（isomorphic-git）+ 本地编辑快照，按时间倒序、图标区分来源、均可回滚/重播。

**Architecture:** 纯函数放 `src/utils/historyTimeline.ts`（mergeTimeline / commitShortHash / countLineDiff / formatTimeTs）可 node 单测；git 读取放 `electron/gitHistory.ts`（isomorphic-git + Node fs，跑 Electron 主进程，经 IPC `git:history`/`git:show`，授权复用 `isAllowedPath`）；本地快照在 `App.tsx` 的 180ms debounce 里经 `addVersion(docId, v)` 落 `versionsByDoc` + localStorage；HistoryPanel 打开时异步拉 git 历史与本地快照合并。渲染进程无 Node fs / 无真实路径，故 git 历史仅 Electron 可用，浏览器 dev 优雅降级为仅本地快照。

**Tech Stack:** React + zustand + isomorphic-git（新增依赖，纯 JS 无需 git CLI）+ Electron IPC（`electron/main.ts` / `preload.ts` / `api.ts`）。测试：`node --import tsx --test tests/*.test.mjs`（与项目现有一致：结构性源码断言 + 纯函数单测 + isomorphic-git 临时仓库集成测试）。

**Spec:** `docs/superpowers/specs/2026-11-12-history-design.md`

## Global Constraints

- **git 历史仅 Electron 可用**：渲染进程无 Node fs；浏览器 dev / 非 Electron → 仅本地快照，不报错。
- **isomorphic-git 为 dependencies**（非 devDependencies）——Electron 主进程打包需要。
- **git 提交上限 50**（`MAX_GIT_COMMITS`），防大仓库逐 commit diff 卡顿。
- **本地快照上限 10**（现有 `MAX_VERSIONS`）。
- **回滚/重播不改仓库**：只载编辑器内容；`git:show` 是只读 blob 读。
- **`git:history`/`git:show` 复用 `isAllowedPath` 闸门**；导入文件时经 `git:authorize` 注册 `diskPath` 进 `allowedPaths`。
- **版本按文档隔离**：`versionsByDoc: Record<docId, DocVersion[]>`（避免 doc B 显示 doc A 快照）。
- **`DocVersion` 扩展**：加 `ts: number`（epoch ms，合并排序）+ `source: 'git' | 'local'`。
- **恢复** `src/utils/versionId.ts`（`nextVersionId`，上轮误删）——本地快照 id 正需要。
- **`File.path` 已弃用** → 用 `webUtils.getPathForFile(file)`（preload 桥 `getPathForFile`），fallback `file.path`。
- **electron 不得 import `src/`**（打包只含 electron/**/* + dist + server）：`electron/gitHistory.ts` 自含 `countLineDiff`，与 `src/utils/historyTimeline.ts` 的小型重复是刻意的（跨模块边界不可共享）。

## Review Focus

1. **非 git 仓库文件 / 浏览器 dev** → 不报错，仅本地快照。测试：`tests/history-timeline.test.mjs`（mergeTimeline 空 git → 纯 local）。
2. **git 文件回滚/重播** → 载入 commit 内容且**不新增重复快照**（suppress 生效）。测试：`tests/history-panel-wiring.test.mjs`（结构断言 HistoryPanel 调 `setVersionSuppressed` 包裹回滚）。

import { test } from 'node:test'
import { mkdtemp, rm } from 'node:fs/promises'

import { join } from 'node:path'
import * as git from 'isomorphic-git'
import fs from 'node:fs'
import { getGitHistory, getGitShow } from '../electron/gitHistory.ts'

async function makeRepo() {
  const dir = await mkdtemp(join(tmpdir(), 'lze-git-'))
  await git.init({ fs, dir })
  return dir
}
async function commitFile(dir, rel, content, msg, t) {
  const abs = join(dir, rel)
  fs.mkdirSync(join(dir, rel.split('/')[0]), { recursive: true })
  fs.writeFileSync(abs, content)
  await git.add({ fs, dir, filepath: rel })
  return git.commit({ fs, dir, message: msg, author: { name: 'a', email: 'a@x.com', timestamp: Math.floor(t/1000) } })
}

test('getGitHistory：提交列表含 changes/ts，getGitShow 读内容', async () => {
  const dir = await makeRepo()
  try {
    const oid = await commitFile(dir, 'doc.md', '# hi\n\nbody\n', 'add doc', Date.now())
    const res = await getGitHistory(join(dir, 'doc.md'))
    assert.equal(res.ok, true)
    assert.equal(res.gitPath, 'doc.md')
    assert.equal(res.commits.length, 1)
    assert.equal(res.commits[0].oid, oid)
    assert.ok(res.commits[0].changes >= 1)
    const show = await getGitShow(join(dir, 'doc.md'), oid)
    assert.equal(show.ok, true); assert.equal(show.text, '# hi\n\nbody\n')
  } finally { await rm(dir, { recursive: true, force: true }) }
})
